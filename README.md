# Maintenance24 Website

A responsive static website for a property maintenance and repair service focused on quote requests and immediate customer contact.

## Included files

- `index.html` — main landing page with hero, services, gallery, testimonials, contact form, and WhatsApp CTA.
- `blog.html` — simple maintenance tips page.
- `styles.css` — responsive styling and layout.
- `script.js` — navigation toggle and contact form handling.

## Features

- Conversion-focused hero section with quote and WhatsApp CTA
- Mobile responsive layout
- Floating WhatsApp button
- Contact form with inline submission confirmation
- Project gallery and testimonials
- Google Reviews call-to-action section
- SEO-friendly metadata and structured content
